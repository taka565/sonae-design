# ソナエデザイン

企業・ホテル・店舗・各種施設の防災研修・訓練、対応計画づくりを支援するサイトです。

2026-10-24の第4版は、ローカルでのレビュー後に公開承認を受けた改修です。GitHub Actionsで検証・公開します。

- 公開先： https://taka565.github.io/sonae-design/
- リポジトリ： https://github.com/taka565/sonae-design

## 第4版の情報設計

トップは、コンパクトな冒頭 → 困りごとから選ぶ3つの入口 → 企業・ホテル・店舗の相談例 → 3サービスの内容と成果物 → 支援の特徴 → 料金・対応範囲・依頼の流れ → 業種別案内 → 行動確認・記録ツール → FAQ → 相談窓口、の順です。

大きな背景写真、横スワイプの業種タブ、質問式ガイド、追従ボタン、本文の遅延表示は整理しました。本文は16px、補足は14px以上を基本とし、文字サイズの変更に追従するrem単位を使っています。

総務担当者・ホテル運営担当者・小規模店舗の経営者を設計上の仮説として使用しています。実際の顧客属性・ユーザーテスト結果ではありません。年齢・性別は画面に掲載していません。

## 編集と確認

Node.jsのみで動作し、外部ライブラリのインストールは不要です。

```powershell
npm run check
npm run build
npm run verify
npm start
```

`npm start` のプレビューは http://127.0.0.1:4187/ 。生成済みの `dist/index.html` はブラウザーで直接開いても内容を確認できます。

- `scripts/build.mjs`：業種別原稿、ACTION OS・読みもの原稿、8ページとsitemapの生成
- `scripts/home.mjs`：トップページの原稿・構成
- `scripts/layout.mjs`：共通ヘッダー・フッター・相談欄、業種別ページの構成
- `dist/style.css`：共通の文字・ナビゲーション・下層ページのスタイル
- `dist/premium.css`：トップページの専用スタイル。共通スタイルへの上書きを積み重ねず、役割を分離
- `dist/app.js`：メニュー、運営情報・プライバシーのダイアログ、読みものの直接リンク、設定の反映
- `dist/settings.js`：確認・公開承認済みの連絡先と運営情報
- `scripts/verify.mjs`：ページと内部リンク・画像、見出し・ID、トップの順序・直接リンクの検証

HTMLは生成物です。原稿や構造を編集した後は `npm run build` を実行します。CSS・JavaScriptには内容から生成したバージョンが付きます。

## 確定していない情報

問い合わせ先、運営者・代表者・所在地、担当者の氏名・経歴・資格・公開可能な実績、具体的な対応地域・オンライン対応条件、料金の具体例、関連メディアURLは未確定です。

プロフィールは推測で掲載せず、相談窓口は「準備中」と表示しています。送信フォームはありません。メールアドレスを `dist/settings.js` の `contactEmail` に設定すると、受付表示と件名付きメールリンクが切り替わります。受付開始前に、運営者・個人情報の取り扱い・サービス条件を確定してください。

費用は内容・人数・実施時間・訪問の有無に応じた個別見積もりとし、訪問地域・オンライン対応は個別確認としています。未確認の金額・無料相談・全国対応・24時間対応等は追加していません。

## 画像と情報の根拠

既存のAI生成画像をイメージと明記して使用しています。トップの研修画像は `readiness-workshop.webp`、業種別画像は `blue-*.webp`。生成プロンプトは `ASSET-PROMPT-V2.txt` と `ASSET-PROMPTS-BLUE.txt` に保存されています。今回、新しい画像は生成していません。

`action-os-screen.png` は2026-10-20の公開ホーム画面です。紹介内容は2026-10-22に照合済みの範囲を維持し、小児・乳児の専用手順が未実装であること等を記載しています。

公的情報は中小企業庁のBCP策定運用指針（2026-10-20確認）、東京都中小企業振興公社のBCP実践促進助成金（2026-10-22確認）の公式案内へのリンクを維持しています。今回のデザイン改修では制度の再調査は行っていません。

## 公開の仕組み

既存のGitHub Actionsは `main` へのpush時にチェック・生成・検証を行い、`dist/` をGitHub Pagesへ反映します。実際の公開結果はActionsの実行結果で確認できます。`.openai/` は公開対象外です。
